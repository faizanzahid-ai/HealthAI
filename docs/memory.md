# Product Memory

The first demo journey is donor-centered because it tests the most important cross-role rule: following a hospital must lead to an immediate per-follower notification when an active blood request is published.

The second journey is patient-centered: search, doctor profile, appointment, messages, report processing, Urdu organization and explicit sharing.

The prototype is intentionally local and fictional. Backend, secure storage, upload transport, actual OCR, push notifications and clinical review remain integration work.
