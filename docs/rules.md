# Product Rules

1. A disease search is a discovery query and never means the patient has that disease.
2. Location permission is optional; manual area and radius search remain usable.
3. Reports are shared only after an explicit user action.
4. AI output is extraction, organization and translation only, never diagnosis, prescribing or dosage changes.
5. Every active blood request requires group, units, hospital, location, urgency and response method.
6. Every active follower receives an independent blood request notification.
7. Fulfilled or closed requests do not generate new notifications.
8. CNIC, private medical information and unnecessary donor data are never public.
9. Demo data is fictional and must not be presented as real clinical or price data.
