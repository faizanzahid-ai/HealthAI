# Product Requirements

Nexcure is a mobile healthcare workspace for patients, doctors, hospitals and blood donors in Pakistan. The prototype prioritizes trusted discovery and connected care actions over a broad social feed.

## Authentication screens

### Login page
- Users can sign in with email and password.
- The screen includes a clear role selector so each account can open in patient, doctor, hospital, or donor mode.
- Demo access remains available for rapid exploration of the prototype.
- The login state must route users to the correct dashboard after successful authentication.

### Sign-up page
- New users can create a profile using full name, email address, password, and selected role.
- Required role options include Patient, Doctor, Hospital, and Donor.
- Sign-up should immediately create a workspace profile and allow access to the app without a backend approval queue.
- The page should guide users toward the core onboarding flow for Pakistan-based healthcare workflows.

## MVP outcomes

- Role-based demo access for patient, doctor, hospital and donor.
- Disease/tumor search that explicitly avoids diagnosis claims.
- Doctor discovery, profiles and appointment requests.
- Hospital pages with follows, posts and blood requests.
- Follower notifications and donor offers for active requests.
- Report processing demo with Urdu summary and explicit sharing.
- Notification, profile and safety states that work without a backend.
- Login and sign-up flow for accessible healthcare onboarding.

## Non-goals

No web app, admin dashboard, real diagnosis, real OCR, real medicine pricing, or real patient data.
