# Design System

Nexcure uses a calm clinical palette: deep teal for trust and actions, navy for high-level workspace banners, off-white for the mobile canvas, white for cards, amber for ratings, green for successful states and red for urgency.

The interface uses 8px spacing increments, 12-17px corner radii, 48px action targets, restrained borders and compact cards designed for scanning. Bottom navigation is role-specific. The visual tone is professional and community-oriented rather than social-media playful.

Accessibility decisions: high contrast text, semantic button roles through React Native touchables, readable minimum sizes, explicit status labels and short error/empty states.
