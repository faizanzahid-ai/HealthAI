# Technical Requirements

- Node.js 20+ and npm.
- Expo SDK 57, React 19.1 and React Native 0.81.
- Portrait-only mobile layout; tablet support is disabled.
- `APP_MODE=mock` is the default behavior.
- No secret keys or personal data in source.
- Run with `npm install` and `npm start`.
- Android and iOS builds are delegated to Expo tooling.

Flutter was unavailable in the development environment, so React Native/Expo is the supported prototype runtime.
