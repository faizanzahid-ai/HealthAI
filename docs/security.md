# Security

The prototype contains only fictional seed data and no secrets. It intentionally does not persist reports, CNICs or tokens.

Before production: use secure token storage, short sessions, server-side role authorization, signed upload URLs, encrypted report storage, malware/file validation, redacted logs, masked donor identity, audit trails and explicit sharing consent. Push notification payloads must avoid private medical details. Clinical AI outputs need uncertainty handling, escalation language and human review.
